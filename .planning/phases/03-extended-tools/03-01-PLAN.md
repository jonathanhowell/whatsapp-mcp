**SQL query** (per D-01, LIKE-only, no FTS5):
```sql
SELECT
  m.Z_PK            AS message_id,
  m.ZCHATSESSION    AS chat_session_id,
  cs.ZPARTNERNAME   AS chat_name,
  cs.ZCONTACTJID    AS chat_jid,
  ppn.ZPUSHNAME     AS chat_push_name,
  m.ZTEXT           AS text,
  m.ZMESSAGEDATE    AS message_date,
  m.ZMESSAGETYPE    AS message_type,
  m.ZISFROMME       AS is_from_me,
  m.ZPUSHNAME       AS sender_name,
  mi.ZMEDIALOCALPATH AS media_path,
  mi.ZFILESIZE      AS media_file_size,
  mi.ZTITLE         AS media_title
FROM ZWAMESSAGE m
JOIN ZWACHATSESSION cs ON cs.Z_PK = m.ZCHATSESSION
LEFT JOIN ZWAPROFILEPUSHNAME ppn ON ppn.ZJID = cs.ZCONTACTJID
LEFT JOIN ZWAMEDIAITEM mi ON mi.Z_PK = m.ZMEDIAITEM
WHERE m.ZTEXT LIKE ? ESCAPE '\\'
ORDER BY m.ZMESSAGEDATE DESC
LIMIT ?
```

For pagination with cursor, add a second SQL variant or conditionally append `AND m.ZMESSAGEDATE < ?` when a `cursor` arg is provided.

- `query`: `z.string().min(1).describe("Search keyword or phrase")` (required)

**LIKE escaping** (per Pitfall 4 in RESEARCH.md): Before wrapping in `%...%`, escape special chars:

**Pagination** (per D-04): Use CAP = 1000, fetch CAP + 1 rows. If rows.length > CAP, set `has_more: true` and `next_cursor` = ISO timestamp of the last returned message. **Grouped-by-chat response** (per D-02): Copy the `chatMap` pattern from `get-messages-since.ts`:
```typescript
const chatMap = new Map<number, { chat_id: number; chat_name: string; messages: object[] }>();
for (const row of returned) {
  if (!chatMap.has(row.chat_session_id)) {
    chatMap.set(row.chat_session_id, {
      chat_id: row.chat_session_id,
      chat_name: row.chat_push_name ?? row.chat_name ?? row.chat_jid ?? "Unknown",
      messages: [],
    });
  }
  chatMap.get(row.chat_session_id)!.messages.push({
    message_id: row.message_id,
    timestamp: appleEpochToISO(row.message_date),
    type: resolveMessageType(row.message_type),
    is_from_me: row.is_from_me === 1,
    sender_name: row.sender_name ?? null,
    text: row.text ?? null,
    media: row.media_path || row.media_title || row.media_file_size
      ? { filename: row.media_title ?? null, file_size: row.media_file_size ?? null }
      : null,
  });
}
```

Error handling: wrap in try/catch, return `{ content: [{ type: "text", text: "Failed to search messages: ${message}" }], isError: true }`.

```sql
  cs.ZUNREADCOUNT     AS unread_count,

  gi.ZOWNERJID        AS owner_jid,
  gi.ZCREATORJID      AS creator_jid,
  gi.ZCREATIONDATE    AS created_at

LEFT JOIN ZWAPROFILEPUSHNAME ppn ON ppn.ZJID = cs.ZCONTACTJID
LEFT JOIN ZWAGROUPINFO gi ON gi.ZCHATSESSION = cs.Z_PK
WHERE cs.Z_PK = ?
```

Query 2 — Active group members (run only when `session_type === 1`):
```sql
SELECT
  gm.ZMEMBERJID    AS jid,
  gm.ZISADMIN      AS is_admin,
  COALESCE(gm.ZCONTACTNAME, ppn.ZPUSHNAME) AS display_name
FROM ZWAGROUPMEMBER gm
LEFT JOIN ZWAPROFILEPUSHNAME ppn ON ppn.ZJID = gm.ZMEMBERJID
WHERE gm.ZCHATSESSION = ?
  AND gm.ZISACTIVE = 1
ORDER BY gm.ZISADMIN DESC, gm.ZMEMBERJID ASC
```
