**Imports:**

**Row interface:**
```typescript
interface ContactRow {
  contact_id: number;
  full_name: string | null;
  given_name: string | null;
  last_name: string | null;
  phone_number: string | null;
  localized_phone: string | null;
  whatsapp_jid: string | null;
  business_name: string | null;
}
```

**SQL query** (per Pattern 3 in RESEARCH.md):
```sql
SELECT
  Z_PK                    AS contact_id,
  ZFULLNAME               AS full_name,
  ZGIVENNAME              AS given_name,
  ZLASTNAME               AS last_name,
  ZPHONENUMBER            AS phone_number,
  ZLOCALIZEDPHONENUMBER   AS localized_phone,
  ZWHATSAPPID             AS whatsapp_jid,
  ZBUSINESSNAME           AS business_name
FROM ZWAADDRESSBOOKCONTACT
WHERE ZFULLNAME LIKE ? ESCAPE '\\'
   OR ZPHONENUMBER LIKE ? ESCAPE '\\'
ORDER BY ZFULLNAME ASC
LIMIT 20
```

**Input schema:**
- `query`: `z.string().min(1).describe("Name or phone number to search for")`

**ContactsV2 path derivation** (per D-07):
```typescript
const contactsDbPath = path.join(path.dirname(config.dbPath), 'ContactsV2.sqlite');
```

**Existence check** (per Pitfall 6): Before opening, check `fs.existsSync(contactsDbPath)`. If not found, return `isError: true` with `"ContactsV2.sqlite not found at ${contactsDbPath} — open WhatsApp Desktop and allow contact sync"`.

**Connection lifecycle** (per Pitfall 2): Open in try block, close in finally block:
```typescript
const contactsDb = new Database(contactsDbPath, { readonly: true, fileMustExist: true });
try {
  // query logic
} finally {
  contactsDb.close();
}
```

Do NOT use `timeout: 0` — no lock contention on read-only connection against infrequently-written ContactsV2.

**LIKE escaping:** Same pattern as search_messages:
```typescript
const escaped = query.replace(/\\/g, '\\\\').replace(/%/g, '\\%').replace(/_/g, '\\_');
const likeParam = `%${escaped}%`;
```
Bind `likeParam` for both WHERE clauses (name and phone).

**Response shape:**
```typescript
{
  contacts: rows.map(r => ({
    contact_id: r.contact_id,
    full_name: r.full_name,
    phone_number: r.phone_number,
    localized_phone: r.localized_phone,
    whatsapp_jid: r.whatsapp_jid,
    business_name: r.business_name,
  })),
  total: rows.length,
}
```

Empty results: return `{ contacts: [], total: 0, note: "No contacts matching query" }` (not an error).

Tool description: `"Look up WhatsApp contacts by name or phone number. Searches the ContactsV2 address book database."`

Annotations: `{ readOnlyHint: true }`.

Error handling: outer try/catch for `isError: true` with `"Failed to get contact: ${message}"`.

**MIME type map** (inline, per RESEARCH.md):
```typescript
const MIME_TYPES: Record<string, string> = {
  '.jpg':  'image/jpeg',
  '.jpeg': 'image/jpeg',
  '.png':  'image/png',
  '.gif':  'image/gif',
  '.webp': 'image/webp',
  '.mp4':  'video/mp4',
  '.mov':  'video/quicktime',
  '.opus': 'audio/ogg',
  '.mp3':  'audio/mpeg',
  '.pdf':  'application/pdf',
  '.docx': 'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
};
```

**Row interface:**
```typescript
interface MediaRow {
  message_id: number;
  message_type: number;
  media_path: string | null;
  media_file_size: number | null;
  media_title: string | null;
}
```

**SQL query:**
```sql
SELECT
  m.Z_PK            AS message_id,
  m.ZMESSAGETYPE    AS message_type,
  mi.ZMEDIALOCALPATH AS media_path,
  mi.ZFILESIZE      AS media_file_size,
  mi.ZTITLE         AS media_title
FROM ZWAMESSAGE m
JOIN ZWAMEDIAITEM mi ON mi.Z_PK = m.ZMEDIAITEM
WHERE m.Z_PK = ?
```

**Input schema:**
- `message_id`: `z.number().int().describe("The message ID from get_messages or search_messages")`

**Size limit constant:**
```typescript
const SIZE_LIMIT = 5 * 1024 * 1024; // 5 MB (D-05)
```

**Media base path** (per anti-pattern warning — use config.dbPath, NOT handle.snapshotPath):
```typescript
const mediaBase = path.join(path.dirname(config.dbPath), 'Message');
```

**Three response branches:**

1. **No media attachment** (JOIN returns no rows): return `isError: true` with `"Message ${args.message_id} has no media attachment"`.

2. **File not found on disk** (per D-06 — normal response, not isError):
```typescript
{
  message_id: row.message_id,
  found: false,
  note: "File not found on disk — may have been deleted or not downloaded",
  metadata: {
    filename: row.media_title ?? null,
    file_size: row.media_file_size ?? null,
    type: resolveMessageType(row.message_type),
  },
}
```

3a. **File over 5 MB** (per D-05 — path only):
```typescript
{
  message_id: row.message_id,
  found: true,
  inline: false,
  filename: row.media_title ?? path.basename(fullPath),
  file_size: stat.size,
  content_type: MIME_TYPES[ext] ?? 'application/octet-stream',
  file_path: fullPath,
  note: "File exceeds 5 MB — use file_path to access directly",
}
```

3b. **File under 5 MB** (per D-05 — base64 inline):
```typescript
const bytes = fs.readFileSync(fullPath);
const base64 = bytes.toString('base64');
const ext = path.extname(fullPath).toLowerCase();
// Response:
{
  message_id: row.message_id,
  found: true,
  inline: true,
  filename: row.media_title ?? path.basename(fullPath),
  file_size: stat.size,
  content_type: MIME_TYPES[ext] ?? 'application/octet-stream',
  data: base64,
}
```

**Path construction:**
```typescript
const fullPath = path.join(mediaBase, row.media_path);
```
Check existence with `fs.existsSync(fullPath)`. Check size with `fs.statSync(fullPath).size`.

Tool description: `"Retrieve a media file (image, voice note, document, video) from a WhatsApp message. Returns base64-encoded content for files under 5 MB, or a file path for larger files. If the file has been deleted or not downloaded, returns available metadata."`

Annotations: `{ readOnlyHint: true }`.

Error handling: outer try/catch for `isError: true` with `"Failed to get media file: ${message}"`.
